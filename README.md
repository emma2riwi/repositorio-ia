# Repositorio de Inteligencia Artificial · Trayecto 1

Entregable T1 del módulo IA Generativa (Riwi · Desarrollo de Software MED C8+).
Tiene tres ejercicios, uno por carpeta.

| # | Ejercicio | Carpeta | Archivos |
|---|-----------|---------|----------|
| 1 | Algoritmo: ordena tres números de menor a mayor | [`ejercicio-1-algoritmo/`](ejercicio-1-algoritmo/) | `ordenar_tres_numeros.py` |
| 2 | Archivo descargable generado en la actividad práctica («Tres cupos, ocho estudiantes») | [`ejercicio-2-archivo-descargable/`](ejercicio-2-archivo-descargable/) | `riwi-tres-cupos-borrador.txt` |
| 3 | Página web hecha con IA: **Overgame**, un buscador de videojuegos según tu ánimo | [`ejercicio-3-pagina-web-ia/`](ejercicio-3-pagina-web-ia/) | `index.html`, `PROMPT.md`, `diseno-de-prompt-inicial.pdf` |

## Ejercicio 1 · Algoritmo

Pide tres números y los muestra de menor a mayor.

```bash
python3 ejercicio-1-algoritmo/ordenar_tres_numeros.py
```

## Ejercicio 2 · Archivo descargable

Es el borrador que descargué de la página de la actividad práctica «Tres cupos, ocho estudiantes». Trae la elección individual, las consultas a la IA y las respuestas.

## Ejercicio 3 · Página web con IA

- `index.html`: la página Overgame. Es un solo archivo, así que basta con abrirlo en el navegador.
- `PROMPT.md`: el prompt que funcionó para construirla.
- `diseno-de-prompt-inicial.pdf`: el diseño del prompt de la sesión de Prompt Engineering (idea, diseño, público, funciones y estilo), del que salió el prompt final.
